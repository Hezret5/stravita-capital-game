# Стравита: Капитал жизни

Браузерная HTML5-игра о личных финансах, созданная для ГП «Стравита» (stravita.by).
Игрок проживает жизнь с 25 до 65 лет, принимает финансовые решения и в финале
получает Индекс финансовой устойчивости, титул и место в рейтинге из 100 участников.

## О чём проект

Игра в лёгкой форме объясняет, как работают накопления, защита и сложный процент:

- **19 карточек событий** — на каждом хода выбор из 2–3 решений, ресурсы меняются сразу;
- **4 ресурса**: Капитал, Защита (страховой щит), Пассивный доход, Финансовая грамотность;
- **щит работает как страхование**: урон сначала поглощает щит, и лишь когда он на нуле — бьёт по капиталу;
- **6 популярных мифов** о деньгах и пенсии разбираются в коротких квизах («Наличка безопаснее», «Пенсия — вопрос после 50» и другие);
- **сложный процент**: капитал и пенсионные накопления растут каждый ход, видно на графике;
- **реальные продукты «Стравиты»**: накопительное страхование жизни, ДНПС, детские и пенсионные программы;
- **финал**: индекс 0–100, один из 5 титулов («Новичок» … «Легенда капитала»), место в рейтинге и 6 ссылок на продукты stravita.by.

Игра проходит за 2–4 минуты. Никаких рулеток и лутбоксов, сбор персональных
данных отсутствует: прогресс хранится только в браузере игрока (localStorage).

## Запуск на компьютере

Нужен Node.js 18 или новее.

```bash
npm install
npm run dev      # режим разработки: http://localhost:5173
npm run build    # production-сборка в папку dist/
npm run preview  # предпросмотр собранной версии
```

Папка `dist/` — полностью автономный статический сайт: её можно открыть двойным
кликом по `index.html` или положить на любой хостинг.

## Как открыть на мобильном телефоне

1. Откройте ссылку игры в любом мобильном браузере: Chrome, Safari, Firefox или Edge (iOS и Android).
2. Игра свёрстана под вертикальный экран телефона (9:16) — ничего настраивать не нужно, работает и в портретной ориентации.
3. Чтобы игра открывалась как приложение, добавьте её на главный экран:
   - **iPhone (Safari)**: кнопка «Поделиться» → «На экран “Домой”»;
   - **Android (Chrome)**: меню (три точки) → «Добавить на главный экран».
4. Прогресс сохраняется в самом телефоне — при следующем открытии игра продолжится с того же места.

## Технологии

- Vite, чистый JavaScript без фреймворков;
- шрифты Inter и Montserrat, брендовые цвета «Стравиты»: зелёный `#009639` и тёмно-синий `#002F6C`;
- вся сборка весит около 0,2 МБ и открывается за 1–2 секунды даже на мобильном интернете.

## Структура проекта

```
src/
  main.js          — экраны и игровая логика интерфейса
  core/engine.js   — состояние, сложный процент, щит, индекс устойчивости
  core/storage.js  — сохранение прогресса (localStorage)
  data/events.js   — 19 карточек событий
  data/myths.js    — 6 мифов с квизами
  data/bots.js     — 99 виртуальных участников рейтинга
  data/config.js   — ссылки на продукты, титулы, экономика
  styles.css       — стили в фирменном стиле «Стравиты»
dist/              — готовая сборка для публикации
```
